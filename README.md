# 💻 ViewHub

ViewHub — десктопное кроссплатформенное приложение для безопасной интеграции с внешними источниками данных через API. Программа отображает полученную информацию в основном окне, ведёт потокобезопасное логирование процессов в отдельной панели и предоставляет модульный интерфейс для настройки параметров работы и аналитики данных.

---

## 🎯 Основные возможности

* **Интеграция с Django API**: Безопасное подключение к удаленному бэкенду на VPS по HTTP-протоколу для авторизации пользователей и обмена данными.
* **Раздвижной многозонный интерфейс**: Главное окно разделено на три независимые зоны (Взаимодействие/Авторизация, Панель вывода данных, Панель логирования) с возможностью изменения их размеров на лету.
* **Централизованное логирование**: Потокобезопасный вывод системных логов в реальном времени прямо на экран с параллельной записью лог-файлов на диск.
* **Динамическое меню действий**: Использование механизма `QStackedWidget` для удобного переключения между главным меню и формами ввода параметров без перезапуска окон.
* **Обработка документов**: Встроенная поддержка анализа табличных данных и работы с отчетами.

---

## 🛠️ Стек технологий

* **Язык программирования**: Python 3.14+
* **Графический интерфейс (GUI)**: PyQt6 (QtCore, QtWidgets)
* **Сетевое взаимодействие**: Requests (HTTP-запросы к API Django)
* **Анализ данных и отчеты**: Pandas, OpenPyXL
* **Системное ядро и логирование**: Встроенные модули `logging` (с кастомными потокобезопасными хэндлерами) и `pathlib` (`Path`)
* **Менеджер зависимостей**: Poetry (v2.0+)

---

## 📦 Архитектура и структура проекта

Проект спроектирован по модульному принципу:
* **`main.py`** — Главная точка запуска и инициализации глобального логгера.
* **`src/windows_pq.py`** — Сборка графического интерфейса `MainWindow`, управление слоями, сигналами и слотами.
* **`src/core/logger.py`** — Системный пакет ядра. Содержит функцию `setup_logger` и кастомный класс `QTextEditHandler`.
* **`src/auth/api_client.py`** — Изолированный сетевой клиент для отправки POST-запросов авторизации на сторону Django.

## 🚀 Установка и запуск

Для управления окружением и зависимостями проекта требуется утилита [Poetry](https://python-poetry.org).

### 1. Подготовка репозитория
Клонируйте проект и перейдите в рабочую директорию:
```bash
git clone https://github.com
cd ViewHub
```

### 2. Установка зависимостей
Poetry автоматически создаст изолированное виртуальное окружение и установит все пакеты (PyQt6, Pandas, Requests, OpenPyXL), зафиксированные в конфигурации:
```bash
poetry install
```

### 3. Запуск приложения
Запустите графический интерфейс в контексте виртуального окружения Poetry:
```bash
poetry run python main.py
```

## 💡 Использование

1. **Главное меню**: При старте приложения нажмите на большую кнопку **«АВТОРИЗАЦИЯ»** в Зоне 1.
2. **Ввод данных**: Заполните поля «Адрес API», «Логин» и «Пароль». При необходимости воспользуйтесь кнопкой **«Показать»** для проверки корректности пароля.
3. **Отправка запроса**: Нажмите кнопку **«Обработать»**. 
   * В Зоне 2 (Результат) отобразится технический отчет по отправленному HTTP-запросу.
   * В Зоне 3 (Логирование) в реальном времени побегут системные логи (`INFO` или `ERROR`), возвращенные сетевым модулем.
4. **Навигация**: Используйте кнопку **«← Назад»**, чтобы вернуться в главное меню для выбора других действий.
