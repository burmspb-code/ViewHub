# ViewHub

ViewHub — приложение для интеграции с внешними источниками данных через API: отображает информацию в основном окне, ведёт логи в отдельном окне и предоставляет интерфейс для настройки параметров работы.

## Основные возможности

- Подключение к базе данных или сайту по API‑протоколу.
- Отображение полученных данных в главном окне приложения.
- Ведение логов в отдельном окне.
- Настройка параметров работы в окне настроек.
