# 💻 ViewHub

ViewHub — десктопное кроссплатформенное приложение для безопасной интеграции с внешними источниками данных через API и гибкого многопоточного парсинга. Программа отображает полученную информацию в основном окне, ведёт потокобезопасное логирование процессов в отдельной панели и предоставляет модульную расширяемую архитектуру для сбора, обработки и аналитики данных.

---

## 🎯 Основные возможности

* **Интеграция с Django API**: Безопасное подключение к удаленному бэкенду на VPS по HTTP-протоколу для авторизации пользователей и обмена данными.
* **Многопоточный асинхронный парсинг**: Архитектура включает фоновые потоки `QThread`, исключающие зависание GUI-интерфейса во время тяжелых сетевых операций.
* **Инкрементальное сохранение данных (Chunked Saving)**: Постраничный сбор данных с немедленной дозаписью порций (чанков) на диск. Это минимизирует потребление ОЗУ и гарантирует сохранность данных при аварийном сбое.
* **Раздвижной многозонный интерфейс**: Главное окно разделено на три независимые зоны (Взаимодействие/Авторизация, Панель вывода данных, Панель логирования) с возможностью изменения их размеров на лету.
* **Централизованное логирование**: Потокобезопасный вывод системных логов в реальном времени прямо на экран с параллельной записью лог-файлов на диск. Ошибки автоматически форматируются до первой строки для чистоты вывода.
* **Динамическое меню действий**: Использование механизма `QStackedWidget` для удобного переключения между главным меню и формами ввода параметров без перезапуска окон.

## 🛠️ Стек технологий

* **Язык программирования**: Python 3.14+
* **Автоматизация браузера**: Playwright (С Chromium в Headless-режиме)
* **Графический интерфейс (GUI)**: PyQt6 (QtCore, QtWidgets)
* **Сетевое взаимодействие**: Requests (HTTP-запросы к API Django)
* **Анализ парсинга**: BeautifulSoup4 (с поддержкой высокоскоростного парсера `lxml`)
* **Анализ данных и отчеты**: Pandas, OpenPyXL
* **Системное ядро и логирование**: Встроенные модули `logging` (с кастомными потокобезопасными хэндлерами) и `pathlib` (`Path`)
* **Менеджер зависимостей**: Poetry (v2.0+)

## 📦 Архитектура и структура проекта

Проект спроектирован по модульному принципу со строгим соблюдением SOLID и паттерна «Стратегия». Слой парсинга полностью изолирован от графического интерфейса:

* **`main.py`** — Главная точка запуска и инициализации глобального логгера.
* **`src/windows_pq.py`** — Сборка графического интерфейса `MainWindow`, управление слоями, сигналами и слотами.
* **`src/exceptions.py`** — Изолированный слой кастомных исключений (например, `ExceptionStopParser`), предотвращающий циклические импорты (Circular Imports).
* **`src/parser_classes.py`** — Набор базовых абстрактных интерфейсов системы парсинга:
  * `BaseConfig` — Базовый контейнер параметров конфигурации (целевой URL, ключевые слова).
  * `BaseExtractor` — Определение логики извлечения данных из HTML (BeautifulSoup).
  * `BaseSaver` — Описание стратегии сохранения данных (методы `.initialize()` для подготовки/очистки файла и `.save()` для инкрементальной записи).
  * `BaseParser` — Интерфейс управления обходом страниц и сетевой логикой (чистый Python-генератор).
  * `BaseParserWorker` — Универсальный фоновый поток `QThread`, управляющий жизненным циклом парсинга и транслирующий безопасные сигналы (`progress_signal`, `finished_signal`) в GUI PyQt6.
* **`src/auth/api_client.py`** — Сетевой клиент для отправки POST-запросов авторизации на сторону Django.
* **`src/parser_work.py`** — Конкретные реализации архитектуры парсинга для целевых площадок:
  * `CitadelConfig` — Конфигурация селекторов карточек, цен и артикулов сайтов группы «Цитадель».
  * `CitadelExtractor` — Парсинг конкретных HTML-структур с защитой от дублирования ссылок и фильтрацией наличия.
  * `CitadelParser` — Итератор страниц на базе Playwright, отдающий данные порциями.
  * `CSVSaver` — Реализация инкрементального сохранения в CSV с поддержкой `utf-8-sig` и открытием файлов в режиме дозаписи (`append`).

## 🚀 Установка и запуск

Для управления окружением и зависимостями проекта требуется утилита [Poetry](https://python-poetry.org).

### 1. Подготовка репозитория
Клонируйте проект и перейдите в рабочую директорию:
```bash
git clone https://github.com
cd ViewHub
```

### 2. Установка зависимостей и драйверов
Poetry автоматически создаст изолированное виртуальное окружение и установит все пакеты (PyQt6, Playwright, lxml, Requests, OpenPyXL), зафиксированные в конфигурации:
```bash
poetry install
```

После установки зависимостей необходимо один раз инициализировать системные бинарные файлы браузеров для Playwright:
```bash
poetry run playwright install chromium
```

### 3. Запуск приложения
Запустите графический интерфейс в контексте виртуального окружения Poetry:
```bash
poetry run python main.py
```

## 💡 Использование

1. **Главное меню**: При старте приложения нажмите на большую кнопку **«АВТОРИЗАЦИЯ»** в Зоне 1 или выберите модуль парсинга.
2. **Ввод данных**: 
   * Для авторизации: Заполните поля «Адрес API», «Логин» и «Пароль» (при необходимости воспользуйтесь кнопкой **«Показать»**).
   * Для парсинга: Задайте имя выходного файла и ключевое слово для поиска в каталоге.
3. **Отправка запроса и парсинг**: Нажмите кнопку **«Обработать»** / **«Старт»**.
   * Выбранный сейвер очистит старый файл на диске, предотвращая наслаивание данных.
   * Фоновый поток начнет сбор данных. В Зоне 2 (Результат) будет отображаться технический отчет или счетчик собранных чанков в реальном времени.
   * В Зоне 3 (Логирование) будут выводиться потокобезопасные системные логи (`INFO` или `ERROR`), возвращенные сетевым или парсинг-модулем.
4. **Остановка и навигация**: Вы можете прервать парсинг в любой момент кнопкой **«Стоп»** — браузер корректно завершит сессию, а уже собранная часть данных сохранится в файл. Используйте кнопку **«← Назад»**, чтобы вернуться в главное меню.
